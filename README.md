### 🏗️ Featured Project

#### 🔐 [Single-ESP32 Smart Home System](https://github.com/sudip_2k6)
**RFID Access Control · Multi-Sensor Automation · Live Web Dashboard · OTA Updates · Voice Control**

A complete smart home system built on a single ESP32, combining security, automation, and remote control in one device.

- 🪪 **RFID-based access control** using an RC522 module for secure entry
- 🌡️ **Multi-sensor automation** — PIR motion, LDR (light), DHT11 (temp/humidity), and MQ-2 gas detection with hysteresis-based triggering
- 🖥️ **Live web dashboard** with a self-hosted REST/JSON API for real-time monitoring and control
- 🔄 **OTA firmware updates** — no need to physically reconnect the device
- 🗣️ **Voice control** via SinricPro integration with Google Assistant
- 💾 **Persistent relay states** across reboots using ESP32 Preferences
- 🔧 4-channel relay control for hallway, room lights, fan, and door lock

> Built and debugged end-to-end — from wiring active-HIGH relays and calibrating gas sensor thresholds, to resolving tricky firmware bugs like conflicting relay-state functions and Arduino library path conflicts.

**Tech used:** ESP32-WROOM-32, RC522 RFID, ST7735 TFT Display, HC-SR501 PIR, MQ-2 Gas Sensor, DHT11, SinricPro, REST/JSON
